# Jishnu VN Portfolio Website

A responsive personal portfolio website built with ReactJS and Vite. It presents my profile, projects, technical skills, certifications, LeetCode progress, and contact information.

## Live website

[Open the portfolio](https://portfolio-webpage-three-gules.vercel.app/)

## Features

- Four React views: About, Projects, Skills, and Contact
- Project search and project-type filtering
- Client-side contact-form validation
- Responsive layout for desktop and mobile screens
- Three.js interactive background scene
- Clickable email, phone, GitHub, and LinkedIn links

## Technology stack

- ReactJS and JSX
- Vite
- JavaScript ES6
- HTML5 and CSS3
- Three.js

## Project structure

```text
src/
  components/
    ChipScene.jsx
    Contact.jsx
    Header.jsx
    Home.jsx
    Projects.jsx
    Skills.jsx
  main.jsx
  style.css
  scene.css
```

## Run locally

```bash
npm install
npm run dev
```

To create a production build:

```bash
npm run build
```
