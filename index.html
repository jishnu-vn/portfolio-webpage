Architecture & Engineering Decisions

Built a real-time multi-tasking firmware stack on the ESP32 (Xtensa LX7 32-bit dual-core processor). In complex embedded devices, concurrency issues like race conditions, priority inversion, and stack exhaustion often cause erratic system crashes.

  • Workload Isolation: Bound network/protocol handlers to Core 0 while isolating critical sensor sampling and real-time control loops strictly on Core 1 using xTaskCreatePinnedToCore().
  • Deterministic Timing: Used vTaskDelayUntil() for precise periodic task invocation without timing drift, achieving predictable 1ms cycle execution.
  • Concurrency Safeguards: Implemented priority inheritance mutexes to guard shared SPI/I2C buses, preventing higher-priority control tasks from starvation during peripheral bus contention.
  • Memory Health Monitoring: Monitored thread stack high watermarks with uxTaskGetStackHighWaterMark() to ensure zero overflow in resource-constrained SRAM.

void vTaskSensorSampling(void *pvParam) {
    TickType_t xLastWakeTime = xTaskGetTickCount();
    const TickType_t xPeriod = pdMS_TO_TICKS(1);

    for (;;) {
        // Read SPI bus guarded by mutex
        if (xSemaphoreTake(xSpiMutex, 5) == pdTRUE) {
            read_hardware_registers();
            xSemaphoreGive(xSpiMutex);
        }
        // Send to Inter-Core Queue (FIFO)
        xQueueSend(xSensorQueue, &sample, 0);

        vTaskDelayUntil(&xLastWakeTime, xPeriod);
    }
}

Monad Canvas

Decentralized collaborative drawing platform where every vector brushstroke is executed as an asynchronous, sub-second transaction.

Architecture & Engineering Decisions

Traditional blockchains like Ethereum (15 TPS) cannot support real-time interactive user inputs due to prohibitive latency and gas costs. Monad Canvas leverages Monad's parallel execution engine (10,000+ TPS with sub-second finality) to treat every stroke as a discrete on-chain state transition.

  • Stroke-as-Transaction: Each user stroke encodes vector coordinates (x1, y1, x2, y2), color payload, brush radius, and cryptographic signature into a compact calldata payload.
  • Parallel State Execution: Taking advantage of Monad's optimistic concurrency control, simultaneous artists paint across independent canvas coordinates without causing state conflicts or block congestion.
  • Sub-Second Finality: Latencies under 50ms ensure that drawn strokes feel immediate to the user while achieving permanent on-chain consensus.
  • Historical Replay: Enables deterministic stroke-by-stroke canvas playback by verifying the sequence of emitted block events.

function recordStroke(
    uint32 x1, uint32 y1,
    uint32 x2, uint32 y2,
    bytes3 strokeColor, uint8 brushWidth
) external returns (bytes32 txHash) {
    uint256 strokeId = totalStrokesRecorded++;
    canvasLedger[strokeId] = VectorStroke({
        x1: x1, y1: y1, x2: x2, y2: y2,
        color: strokeColor, width: brushWidth,
        artist: msg.sender, blockTime: block.timestamp
    });
    txHash = keccak256(abi.encodePacked(strokeId, msg.sender));
    emit StrokeCommitted(strokeId, txHash);
    return txHash;
}
